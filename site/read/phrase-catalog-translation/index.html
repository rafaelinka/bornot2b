Phrase: a catalog translation ends with a product check

Exporters need more than fluent sentences: intact SKUs, units, delivery terms, and a controlled path back into the finished file.

Review status: not tested. We reviewed public instructions, release notes, and pricing as of November 27, 2026. We did not upload catalogs, order translations, or measure translation-engine quality. This is an assessment of the workflow and a proposed pilot.

A fluently translated product page can sell the wrong item. Lose a leading zero in a SKU, turn a temperature range into a single number, or return text to the neighboring language column, and the commercial meaning changes. For an exporter, translation is an operation on product data. The buyer must receive the same product and the same promise in another language.

This week's trigger: mandatory terms and the return trip

Phrase's November 23 bulletin reports stronger Strict terms checks, centralized connection management, and a Document360 connector. It also fixes multilingual CSV handling and output to hidden target-language Excel columns. The bulletin summarizes the preceding week; it does not provide deployment dates for every change.

This is a reason to examine an established TMS workflow, rather than describe the whole system as new. Two issues matter. An approved term must survive work by several translators, and a correct translation must return to the correct cell. Failure in the second stage can erase the value of the first.

What should go to the translator?

Start with a separate text layer: SKU, source description, context, target languages, and length limits. Keep prices and numeric characteristics in a governed product source and join them through a key. That is our architectural recommendation, not a claim that Phrase automatically protects every numerical column.

Context must explain where the wording appears. “Up to 30 days” carries a different risk in a general help page and in an individual quotation. A translator can choose impeccable grammar and inadvertently strengthen the supplier's promise. A commercial editor therefore checks the commitment; a product specialist checks specifications and units.

A translation system cannot replace ownership of the product master. If engineering and sales use different names for the same coating, the company must first resolve the disagreement. Automation distributes the chosen wording; it cannot determine which description matches the actual product.

Translation memory is an asset with an owner

A translation memory stores translated segments; a term base contains approved terminology. Their jobs differ: reusing a sentence and enforcing a product name are not the same control. An old sentence may remain grammatically correct after the configuration, warranty, or permitted application has changed.

Our recommendation is an owner, scope, and review date for important terms, especially materials, operating limits, packaging, and service. Resolve terminology disputes before mass translation. Otherwise, a late correction turns into a search for every downstream file that inherited the old wording.

Phrase QA compares source and target segments and supports configurable checks, including terms, numbers, and tags. A project manager can make QA mandatory. However, no warnings means only that the selected rules found no reportable violations. It is not independent evidence that the technical description is accurate.

The control must not become a stream of noise. If a glossary demands one form across incompatible grammatical or technical contexts, people will learn to dismiss warnings. A useful pilot counts false positives requiring expert decisions as well as errors caught.

Excel: translating text and preserving a workbook are different tasks

The documentation states a limitation for specific filters: Multilingual Excel, Excel with HTML processing, and conversion to TMS tags use XML conversion; most formatting, charts, and images are lost, as are XLSM macros. This applies to those modes, not every Excel file without exception. Merged target cells also need attention to format limitations.

A practical architecture extracts controlled text and assembles the customer document again from verified data. A well-designed source catalog is not preserved merely because an upload succeeded. The return trip needs checks of language, structure, and commercial meaning.

A hidden column is not deleted information. Standard and multilingual import modes have different settings. Remove purchase prices, internal notes, and personal contacts from the handoff copy when they are unnecessary. Being outside the visible worksheet area is not an access-control policy.

Who can make the final change?

The documented TMS workflow has an important property: after a segment is edited or confirmed in a later step, subsequent edits from an earlier step no longer propagate automatically into it. This is documented behavior, not a defect established by our testing. Teams need an explicit reopening and reconciliation procedure.

Consider a hypothetical engineer correcting a maximum temperature after editorial approval. A notice that the source has changed does not prove the final target file contains the new number. Someone must own the version and acknowledge that particular correction. Publication should bind a product-data version to its translation version.

Centralized connections may reduce credential maintenance. Permission to connect a knowledge base and permission to send any article from it are still different decisions. A fictional-data pilot can establish the information route before production documents enter it.

How much is the removed manual work worth?

The official USD page lists Team at $1,245 per month billed annually, or $14,940 for a year. Unlimited TMS seats does not imply unlimited consumption across the platform: products have capacity limits. There is a 14-day trial; check the integrations and additional charges against the intended order.

The subscription is only part of the budget. Add translators, an industry editor, glossary preparation, file handling, layout reconstruction, and maintenance of source connections. Connecting machine translation does not itself establish savings.

Take an editorial example, not Phrase customer data: 12 monthly coordination hours at $30 cost $360. Eliminating every one of those hours would still not cover the listed subscription. The business case must come from a different scale: a repeatable multilingual flow, expensive corrections, or faster assortment availability. For an occasional catalog, a translator using their own CAT tool and handing the memory and glossary back to the client may be a simpler alternative.

A pilot must finish with a usable catalog

We propose 30 fictional SKUs and two target languages. Include leading-zero identifiers, 0.25 kg, “6 × 250 g,” a +2 to +6 °C range, a nontranslatable price column, a hidden target column, and an HTML tag. Deliberately insert an incorrect mandatory term and an extra number to test the chosen controls.

StageEvidence requiredReason to stop
ExtractionRequired text reaches the intended languagesA row, language, or key disappears
EditingControls detect the seeded errorsA changed characteristic goes unnoticed
ReassemblySKUs, numbers, and terms survive in the final fileA correct translation belongs to another product

A manual correction is acceptable, but its time belongs in the process cost. The required output is an openable, checked customer file, rather than a completed job status. We have not performed these tests.

Finally, assess portability concretely. The documentation supports memory export, including TMX, and recommends backups before irreversible changes. A memory file does not automatically reproduce project settings, permissions, or connections. Phrase is worth examining when a company already governs its source product and wants to scale language versions. A translation platform will not create the missing responsibility for that product.
