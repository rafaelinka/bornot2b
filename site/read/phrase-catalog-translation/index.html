Phrase: a catalog translation ends with a product check

Exporters need more than fluent sentences: intact SKUs, units, delivery terms, and a controlled path back into the finished file.

Review status: not tested. We reviewed public instructions, release notes, and pricing as of November 27, 2026. We did not upload catalogs, order translations, or measure translation-engine quality. This is an assessment of the workflow and a proposed pilot.

A fluently translated product page can sell the wrong item. Lose a leading zero in a SKU, turn a temperature range into a single number, or return text to the neighboring language column, and the commercial meaning changes. For an exporter, translation is an operation on product data. The buyer must receive the same product and the same promise in another language.

This week's trigger: mandatory terms and the return trip

Phrase's November 23 bulletin reports stronger Strict terms checks, centralized connection management, and a Document360 connector. It also fixes multilingual CSV handling and output to hidden target-language Excel columns. The bulletin summarizes the preceding week; it does not provide deployment dates for every change.

This is a reason to examine an established TMS workflow, rather than describe the whole system as new. Two issues matter. An approved term must survive work by several translators, and a correct translation must return to the correct cell. Failure in the second stage can erase the value of the first.

What should go to the translator?

Separate descriptions from governed product data: send the SKU, text, context, target languages, and length limits, then join prices and specifications through the key. That is our workflow recommendation, not a claim that Phrase automatically protects every numeric column.

One card: fluent English, the wrong order

Consider an entirely fictional V-6 valve, SKU 000104-A. Specification R3 defines a box of six valves, a price per box, and a maximum operating temperature of +80 °C. The commercial condition is delivery within 30 days after order confirmation. The table is an editorial example of rejected and corrected wording, written manually. It is not Phrase output or a translator's actual work.

These errors have different consequences. A missing zero breaks the product link; boxes instead of pieces change quantity; a price per valve rather than per box changes the offer. Fahrenheit instead of Celsius changes the specification, while removing the event that starts the delivery clock changes the supplier's promise. “The English reads well” cannot settle all of them.

In our proposed workflow, the product specialist confirms that the SKU, configuration, and temperature match R3. The commercial editor checks the price unit and delivery condition. The release owner records the approved pair: R3 and translation version EN-07. Product data retains its own owner: if engineering and sales disagree about what is being sold, a language system cannot resolve that dispute for them.

Translation memory is an asset with an owner

A translation memory stores translated segments; a term base contains approved terminology. Reusing a sentence and enforcing a product name serve different purposes. In our card, the V-6 name can remain unchanged without making an old temperature sentence appropriate for a new configuration.

Important terms benefit from an owner, scope, and review date, especially materials, operating limits, packaging, and service. If a correction applies only to a new revision, replacing it across every old description could be wrong: some documents may still accompany products already delivered.

Phrase QA compares source and target segments and supports configurable checks, including terms, numbers, and tags. A project manager can make QA mandatory. A number warning can help locate a difference between 80 and 70; the specification determines whether either number is technically appropriate. No warnings means only that the selected rules found no reportable violations.

False positives also have a cost. If a glossary demands one form across incompatible grammatical or technical contexts, people learn to dismiss the signals. A useful pilot counts errors caught and warnings requiring expert decisions.

Excel: translating text and preserving a workbook are different tasks

The documentation states a limitation for specific filters: Multilingual Excel, Excel with HTML processing, and conversion to TMS tags use XML conversion; most formatting, charts, and images are lost, as are XLSM macros. This applies to those modes, not every Excel file without exception. Merged target cells also need attention to format limitations.

A practical architecture extracts controlled text and assembles the customer document again from verified data. A well-designed source catalog is not preserved merely because an upload succeeded. The return trip needs checks of language, structure, and commercial meaning.

A hidden column is not deleted information. Standard and multilingual import modes have different settings. Remove purchase prices, internal notes, and personal contacts from the handoff copy when they are unnecessary. Being outside the visible worksheet area is not an access-control policy.

Who can make the final change?

The documented TMS workflow has an important property: after a segment is edited or confirmed in a later step, subsequent edits from an earlier step no longer propagate automatically into it. This is documented behavior, not a defect established by our testing.

Continue the same fictional card. Engineering issues R4, reducing the temperature limit from +80 to +70 °C. EN-07 has already passed editing against R3. “Source updated” is not enough to authorize publication. In our proposed release procedure, the release owner holds that card; the product specialist confirms the new limit, the translator enters it in EN-08, and the release owner reconciles the finished file with R4 / EN-08. That includes checking captions and other language columns for the old temperature. A new version means closing this particular correction, not merely giving a file a new date.

Centralized connections may reduce credential maintenance. Permission to connect a knowledge base still does not authorize sending every article from it. A first pass with the fictional card establishes the information route before production documents enter it.

How much is the removed manual work worth?

The official USD page lists Team at $1,245 per month billed annually, or $14,940 for a year. Unlimited TMS seats does not imply unlimited consumption across the platform: products have capacity limits. There is a 14-day trial; check the integrations and additional charges against the intended order.

The subscription is only part of the budget. Add translators, an industry editor, glossary preparation, file handling, layout reconstruction, and maintenance of source connections. Connecting machine translation does not itself establish savings.

Take an editorial example, not Phrase customer data: 12 monthly coordination hours at $30 cost $360. Eliminating every one of those hours would still not cover the listed subscription. The business case must come from a different scale: a repeatable multilingual flow, expensive corrections, or faster assortment availability. For an occasional catalog, a translator using their own CAT tool and handing the memory and glossary back to the client may be a simpler alternative.

A pilot must finish with a usable catalog

Card 000104-A is the start of a control set, not evidence that the service works. We propose 30 fictional SKUs and two target languages. Alongside leading-zero identifiers, include 0.25 kg, “6 × 250 g,” a +2 to +6 °C range, a price column excluded from translation, a hidden target-language column, and an HTML tag. A deliberately incorrect mandatory term and an extra number test the selected QA rules.

A completed pass must produce a customer file in which every row retains its key and language, numeric specifications match the approved revision, and the final corrected segment reaches publication. A translation assigned to the neighboring SKU is unfinished work even if the job status says complete. Manual reconstruction time belongs in the process cost. We have not performed these tests in Phrase.

The documentation supports memory export, including TMX, and recommends backups before irreversible changes. One memory file does not automatically reproduce every project setting, permission, and connection. An exit assessment should include reconstructing at least one approved card and its link to the product data.

Phrase is more relevant to a company with a recurring multilingual flow and governed source descriptions. There, the platform can support repeatable work across several participants. For occasional updates, compare it with a translator who returns finished files, memory, and a glossary to the customer. The decision turns on the cost of publishing a correct product description and its next revision, not just the speed of the first translation.
